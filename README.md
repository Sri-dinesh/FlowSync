# FlowSync

Traffic-signal simulation, interactive inspection and reproducible control research.

[CONTENT.md](CONTENT.md) is the single maintained reference for the application,
architecture, setup, data flow, technique attribution, research evidence and limits.

FlowSync is a simulation research prototype. Camera/signal deployment readiness,
architectural novelty and reliable learned-controller superiority are not established.
